# Portafolio Personal | Oscar Andrés Miranda López

Portafolio web de **Oscar Andrés Miranda López**, Java Full Stack Developer Jr. e Ingeniero en Sistemas Computacionales con más de 3 años de experiencia en automatización RPA.

🔗 **Ver sitio en vivo:** [oscarandres008.github.io/portafolio](https://oscarandres008.github.io/portafolio/)

## Acerca del proyecto

Este sitio presenta mi perfil profesional, las tecnologías con las que trabajo, mis proyectos, experiencia, educación y certificaciones. Está pensado como carta de presentación para reclutadores y equipos de desarrollo.

## Secciones

- **Inicio:** presentación y enlaces a GitHub, LinkedIn y descarga de CV.
- **Sobre mí:** mi transición de la automatización al desarrollo Full Stack.
- **Tecnologías:** backend, frontend, herramientas y automatización.
- **Proyectos:** Toro Forrajero (e-commerce), Landing Page del Hackathon y Extracción Inteligente de Datos con UiPath.
- **Experiencia:** trayectoria como Desarrollador RPA.
- **Educación y certificaciones:** formación académica y certificaciones (UiPath, Rocketbot, Automation Anywhere).
- **Contacto:** formulario de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3 (diseño responsive)
- JavaScript
- GitHub Pages para el despliegue

## Estructura del repositorio

```
portafolio/
├── index.html      # Estructura principal del sitio
├── style.css       # Estilos
├── script.js       # Interactividad
├── Imagenes/       # Imágenes del sitio y de los proyectos
├── Cv/             # Currículum en PDF
└── Video/          # Demos de proyectos
```

## Ejecutar en local

```bash
git clone https://github.com/OscarAndres008/portafolio.git
cd portafolio
```

Después abre `index.html` en tu navegador. También puedes usar la extensión **Live Server** de VS Code.
